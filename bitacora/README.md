# 📔 Bitácora del proyecto

Esta carpeta recoge, en orden cronológico, un **resumen de los cambios, decisiones de diseño y decisiones técnicas** que se van tomando en el desarrollo del portfolio de Anabel Pérez Lara.

La idea es tener un registro claro de *qué* se hizo, *por qué* y *cómo*, para poder retomar el proyecto en cualquier momento sin perder contexto.

## Cómo usar esta carpeta

- Cada entrada es un archivo con el formato `AAAA-MM-DD-titulo-corto.md`.
- Se añade una entrada nueva cada vez que hay un cambio o decisión relevante (no para cada commit trivial).
- Cada entrada sigue la plantilla: **Contexto → Cambios → Decisiones → Pendiente**.
